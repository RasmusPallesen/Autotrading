Kill Switch Architecture

  • Daily equity loss reaches 2% → Kill switch activates automatically
  • Every subsequent trade request returns "Kill switch active"
  • Push notification sent immediately via ntfy.sh
  • Agent continues running — only trading halted
  • Manual operator confirmation required to reset
  • Every activation is logged with timestamp and reason

Opportunity-Cost Selling Rules

When the system wants to add a high-conviction position but the portfolio is full (15 positions), it evaluates the weakest holding. It will never sell:

  • A winner with >10% unrealised gain
  • A position within 7 days of a strong earnings beat
  • A position with BULLISH research conviction >70%

Only proceeds if new opportunity has a 15%+ confidence gap over the weakest position.
